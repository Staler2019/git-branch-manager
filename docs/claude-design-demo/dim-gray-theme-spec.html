程式碼耦合（新增主題時真正會壞掉的地方）

gbm_theme.dart:11      brightness = variant == darkTechnical ? dark : light
                       → dim-gray 會被當成淺色主題，Material 預設值全部吃錯
tokens.dart:481/491/501 shadow alpha 用 == darkTechnical 判斷
gbm_theme.dart:86-88   context.gbmThemeVariant：從 brightness 反推 variant
                       （本來就不可逆：neutral 會變成 lightIde）；呼叫端只有 5 個 shadow*
theme_mode_provider    _readSaved 的 switch 要加 'dimGray'
theme_switcher_buttons 第四個色塊
preferences_dialog:920 顯示文字（switch 有窮舉，漏寫的話編譯器會擋）
workspace_screen:1040  viewTheme 循環切換，讀的是 values，自動涵蓋

做法：在 enum 上加一個 bool isDark 當唯一的判斷來源；shadow 改成接受 Brightness 參數，把那個不可逆的反推刪掉。
