02

TAGS / STASH 的四種狀態

收合是 per-repo 的 session 狀態。filter 有輸入時強制展開，但不會改寫記住的狀態，所以清空後會回到收合。

A預設：全部展開
BTAGS 收合：標題和數量都留著
CTAGS 收合中輸入 filter「v0.5」：強制展開；STASH 0 命中 → 整段隱藏
D清空 filter：回到 B

Inferred：沒有出處、由我選的值（已裁定照用）

#值為什麼這樣選
I1標題左內距 12 → 8px（space2）chevron 加在文字左邊；改成和資料夾列相同的 space2 水平內距，避免文字右移太多。
