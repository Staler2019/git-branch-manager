Windows 上抓得到進度嗎

  • 閒置判定看的是「任何一條管線有資料」。Windows 的 stderr 讀取執行緒每讀到一段就更新進度時間（ProcessRunner.cpp:619），stdout（:759）、stdin（:647）也一樣，所以 --progress 的輸出會被算成有傳輸。這是讀程式碼得到的結論，還要用測試證明。
  • 證明方式：在 Windows CI 跑兩個新測試。(1) 從本機 file:// 遠端 fetch --progress，斷言 stderr 管線確實收到進度輸出（git 只有加 --progress 才會對 pipe 印）；(2) 一個持續輸出進度、總時間超過閒置上限的子行程不會被砍，一個完全不出聲的子行程會在閒置上限被砍。這兩個測試都會在 PR #177 的 Windows CI 上跑，結果列進 ledger。
  • 進度列以 \r 覆寫同一行。寫進 Log 的 stderr 只保留每行最後一段，錯誤分類照樣看得到 fatal: 行。
