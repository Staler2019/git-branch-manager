可以填多大、多小

使用者裁定 2026-10-31：畫面 1「照稿」；範圍「B. 500–20000」。
現有的 _NumberField 只接受正整數，沒有上下限；打到一半或 0 不寫入，畫面上沒有任何錯誤提示。行數上限有效能後果：20,000 行開啟 530 ms、捲動每幀 47–57 ms，超過預算，這也是上限定在 5,000 的原因；20,000 以上沒量過（working_copy_diff_pane.dart:56-59）。請選一種。
