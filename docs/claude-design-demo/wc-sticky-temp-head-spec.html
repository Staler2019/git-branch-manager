一次性 block 的 head 置頂

長距離拖曳之後，一次性 block 的上緣和它的 Stage／Unstage 按鈕常常已經捲出畫面，所在的卡片甚至沒被建出。依你的裁定改用 sticky head：block 還在畫面上時，head 黏在 viewport 頂端。

什麼時候出現

  • 出現：一次性 block 的 head 上緣在 viewport 上緣之上（已捲出，或所在的 item 沒被建出），而 block 最後一列的下緣仍在 viewport 上緣之下。
  • 不出現：真正的 head 在畫面內，所以畫面上永遠只有一顆按鈕；block 整個捲出畫面；拖曳中（block 本來就在放開後才出現）。
  • 兩種模式都有：片段與全檔都有；2 file 每側各自判斷。片段模式沒有 ruler，右緣是 18 而不是 32。目前只有全檔模式的 view 有 Stack（放 ruler），片段模式要在出現 sticky head 時也包一層 Stack。
  • 按下：與 block 內的按鈕是同一個 callback（_submitTemporary），payload 不變。
  • 使用者裁定（2026-10-25）：「可以照著實作，但是 跨 2 個 hunk 這文字不需要顯示出來」；追問後裁定「兩處都拿掉」，block 內的 head 與置頂版都只寫「臨時選取」。INF-5「不加」陰影。對比度：「開issue,說明影響範圍」，見 #200。
  • 沿用與新增：head 的內容（底色、padding、label、pill、按鈕）沿用 block 內的 head；外圍的虛線外框是新加的（INF-4）。block、卡片本身的畫法都不變。

用猜的部分（需要你裁定）

#猜的值理由
INF-1樣本的高度、捲動位置、pane 底色、列內容、卡片 head 省略的 badge 與按鈕只是示意；實作沿用既有元件，不改。
INF-2貼在 viewport 頂端（top 0）外框是每個 item 各畫一段，捲動後最上面就是列本身，沒有留白。
INF-3水平範圍對齊 block：左 20（8+9+3），右 32（8+9+14+1），片段模式右 18；不跟著橫向捲動 更正（2026-10-25，使用者裁定「對齊 block 實際位置」）：內容比畫面寬時，左右取 block 在畫面上的實際位置與 view 的交集，跟著橫向捲動；block 邊緣在畫面外的一側不畫虛線與圓角。置頂版放在 ruler 之下。補充（2026-10-25，使用者裁定「右緣留出捲軸的寬度」）：右側最多延伸到 view 右緣往內 10（Flutter 桌面版 Material Scrollbar 預設 thickness 8 + crossAxisMargin 2，GbmCodeHScroll 未設主題；出處是 SDK，不是 spec）；block 右緣落在這 10 之內時，視同在畫面外。真正的 head 在橫向捲動的內容裡，會跟著捲走；置頂版放在 view 的 Stack（和 ruler 同層），按鈕永遠看得到。 固定 20／18 時，真正的 head 隨內容延伸並橫向捲動，置頂版左右會露出一條真正的 head（像素取樣證實）。對齊之後剛好蓋住它；label 與按鈕仍在可見範圍內。延伸到右緣時會蓋住垂直捲軸 thumb 的上段約 31px，也會攔下拖曳 thumb 的手勢，所以右側讓出捲軸的寬度。
INF-4左右畫 1px dashed accent，下方沿用 head 本身的虛線，下方圓角 r4，上方不畫。左右邊框佔 1px，所以內容比 block 內的 head 內縮 1px看起來是 block 的虛線外框被 viewport 上緣截斷。
INF-5不加陰影卡片有 shadowSm（hover 時 shadowMd），但 spec 沒有替「蓋在列上方的浮起 head」定陰影；accentSubtle 的實心底已經擋住底下的列。要加的話，沿用 shadowSm 最接近。
INF-6樣本 C 不提供任何指引ruler 目前不標一次性 block；要標的話是另一個設計。

Audit 結果

  • 結構檢查：0 個不成對、0 個未關閉的標籤。
  • Token 涵蓋：三組色盤沒有用了卻沒定義的 token，也沒有定義了沒用的。所有 hex 都與 tokens.dart 相同。
  • 對比度低於 4.5（照實回報，沒有改；兩者都是 block 內既有 head 本來就有的值）：一次性 pill 在 accentSubtle 底上，neutral 2.95、light-ide 4.29、dark 5.72；primary 按鈕白字在 accent 底上，三組都是 3.75。
  • spec-auditor 第二輪（複審）：150 個值中 126 個符合、2 個不符（marker 對齊、按鈕高度少了 box-sizing）、2 個無出處，另有 2 處文字與 CSS 矛盾（sticky 上緣、陰影的說法）；本版全部改正。INF-3 的 20／32／18 與 ruler 的 17／13／10 經複審確認正確。
  • spec-auditor 第一輪：15 個不符、5 個無出處。最嚴重的是 INF-3 少算了 well 外側的 8px（原本寫左 12／右 24），本版已改正。其餘不符也已照 app 改正：卡片外環、卡片 head、行號欄、虛線外框不佔版面、label 可換行、按鈕的透明外框與字型。
